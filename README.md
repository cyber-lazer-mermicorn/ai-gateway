# AI Gateway
## One API, All Providers

A unified API that routes requests to the best AI provider based on cost, speed, and quality.

**Live:** https://ai-gateway.vercel.app

---

## What This Demonstrates

### Smart Routing
- Cost-optimized selection
- Speed-optimized selection
- Quality-optimized selection

### Provider Fallback
- Automatic failover
- Load balancing
- Circuit breaker

### Analytics
- Usage tracking
- Cost monitoring
- Performance metrics

---

## Getting Started

```bash
git clone https://github.com/cyber-lazer-mermicorn/ai-gateway.git
cd ai-gateway
npm install
npm run dev
```
